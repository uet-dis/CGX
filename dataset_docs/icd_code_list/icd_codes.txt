# ICD-10 Code List for Heart Failure (CGX Focus)

This list defines the clinical scope focused exclusively on Heart Failure for the CGX knowledge graph.

## 1. Methodology
The code list was developed through the following clinical validation process:
- **Data Source:** Based on the **WHO ICD-10 Classification (Version: 2019)**.
- **Search Scope:** Focused on Chapter IX (Diseases of the circulatory system - I00-I99).
- **Selection Criteria:** 
    1. Included the entire **I50** group (Primary codes for Heart Failure).
    2. Filtered combination codes where Heart Failure is a mandatory component (e.g., I11.0).
    3. Cross-referenced with clinical guidelines (ESC/AHA) to ensure alignment with real-world hospital diagnosis patterns.

## 2. Core Heart Failure Codes
- **I50.1**: Left ventricular failure
- **I50.2**: Systolic (congestive) heart failure (HFrEF)
- **I50.3**: Diastolic (congestive) heart failure (HFpEF)
- **I50.4**: Combined systolic and diastolic heart failure
- **I50.9**: Heart failure, unspecified

## 3. Related Cardiovascular Conditions & Comorbidities
- **I11.0**: Hypertensive heart disease with heart failure
- **I13.0**: Hypertensive heart and renal disease with heart failure
- **I13.2**: Hypertensive heart and renal disease with both heart failure and renal failure
- **I42.0**: Dilated cardiomyopathy
- **I48**: Atrial fibrillation and flutter
- **E11**: Type 2 diabetes mellitus
- **N17-N19**: Renal insufficiency
- **E66**: Obesity
- **D50**: Iron deficiency anemia
- **I97.1**: Postcardiotomy heart failure

*Note: Every entity in the CGX knowledge graph must link directly or indirectly to the Heart Failure conditions listed above.*
